# 채팅 금칙어 사전 v1
#
# 정책의 정본은 docs/designs/chat-community-design.md 와 운영 정책 문서다. 이 파일은 사전의
# 버전 고정본이고, 판정 규칙은 BlockedTermDictionary.kt 가 소유한다.
#
# 채팅 본문은 ChatModeration.requireAllowedCharset 가 한글·ASCII 라틴·숫자만 허용하므로
# 키릴·아랍·한자·가나로 쓴 욕설은 애초에 입력되지 않는다. 그래서 외국어 욕설은 로마자
# 표기와 한글 음차만 싣는다.
#
# 구획마다 일치 규칙이 다르다. 규칙과 그 이유는 BlockedTermDictionary.kt 주석에 있다.
#   [korean]          자모 부분 일치. 음절 경계가 맞을 때만 인정한다.
#   [korean-word]     정상 단어에 묻히기 쉬운 말. 토큰 앞에서 시작할 때만 막는다.
#   [korean-initials] 초성체. 입력에 직접 찍힌 자모만 본다.
#   [latin]           부분 일치. 다른 단어에 묻혀도 걸리므로 긴 철자만 넣는다.
#   [latin-word]      단어가 같을 때만 막는다. 짧거나 흔한 철자를 여기에 둔다.
#   [allow]           금칙어를 품지만 정상인 표현.
