# Cozy HUD v9 shared controls

`close-button-v9.png` is the approved neutral-ivory, dark-espresso pixel close button promoted to a shared asset. Character, equipment, inventory, gems, skills, market, settings/profile, and battle history import this same file. The common visual contract is a `60×60` button with a `56×56` image; responsive screens compensate for their parent zoom so the final rendered size stays consistent.
